# NAVI MEAL (Expo Go)
1. `npm install`
2. `npx expo install expo-status-bar expo-font expo-location react-native-maps react-native-safe-area-context @react-native-async-storage/async-storage @expo/vector-icons @expo-google-fonts/poppins`
3. `npx expo start` and scan the QR code with Expo Go.
Tracking is a simulated rider (about 30 s). Data is local mock data in src/data.js.
